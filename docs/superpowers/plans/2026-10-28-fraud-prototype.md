# Fraud workspace prototype
Approved direction: a connected UI prototype using dashboard, table, and form references.
Technology: TypeScript, React, Tailwind, Next.js App Router conventions served by the Sites Vinext compatibility runtime. No production backend, authentication, or Convex integration.
Implementation: shared light/dark tokens and responsive shell; fictional case dataset; searchable/filterable/paginated tables; metric navigation; modal case details and validated session-local create/edit forms; reports export and illustrative audit timeline.
Validation: TypeScript check, framework build, browser inspection of dashboard and interactive form/table flow. Demo changes reset on reload. Production permissions, audit logging, attachments, and reference generation remain future dependencies.
